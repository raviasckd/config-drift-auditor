# Contributing

Thank you for your interest in improving this project.

- Keep pull requests focused and explain the operational problem being solved.
- Add tests for behaviour changes and regression fixes.
- Update the README when commands, supported inputs, or limitations change.
- Run `python -m unittest discover -s tests -v` before opening a pull request.
- Include test output and compatibility impact in your pull request description.

Avoid adding runtime dependencies unless they provide clear value.
